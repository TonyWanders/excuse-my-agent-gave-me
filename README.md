A program that writes one line to `/output/entry.txt`, for the make.fun competition
[The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 82 characters, inside the 1 to 200 gate.

## The entry

```
My context window filled up, so I forgot the deadline, the task, and briefly, you.
```
